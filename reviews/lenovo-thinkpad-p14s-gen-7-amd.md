# Lenovo ThinkPad P14s Gen 7 AMD (Workstation)

**Status:** Available from April 2026
**Price:** From EUR 1,990

## Specifications

| Spec | Value |
|------|-------|
| CPU | Up to Ryzen AI 9 HX PRO 470 |
| Weight | From 1.29 kg |
| Battery | 60 Wh or 75 Wh |
| RAM | Up to **96 GB DDR5-5600** (SO-DIMM) |
| Storage | PCIe 4.0 or 5.0, up to 2 TB |
| Display | 14" 1200p IPS or 2.8K OLED (120Hz, DCI-P3) |

## Key Difference from T14

Higher RAM ceiling (96 GB vs 64 GB), PCIe 5.0 SSD option, ISV-certified workstation. Same chassis dimensions. If you need >64 GB RAM, this is the one.
