# Framework 13 Pro (2026)

**Status:** Announced April 21, 2026. Ships June 2026 (Intel). AMD ships July 2026.
**Price:** From $1,199 (DIY) / $1,499 (pre-built)

## Specifications

| Spec | Value |
|------|-------|
| CPU (AMD) | Ryzen AI 9 HX 370 (Strix Point, NOT Gorgon Point) |
| Weight | 1.4 kg |
| Battery | **74 Wh** (21% up from prior gen) |
| RAM | LPCAMM2, up to 64 GB LPDDR5X-7467 (user-replaceable) |
| Display | 13.5" 2880x1920 (3:2), 700 nits, 1800:1 |
| Thickness | <16 mm |

## Major Changes

- Full CNC aluminum chassis (ground-up redesign)
- Haptic touchpad
- Touch display option
- LPCAMM2 memory (replaceable, unlike soldered LPDDR5X in most ultrabooks)
- Wi-Fi 7 (Intel BE211)
- **First Framework laptop Ubuntu Certified by Canonical**
- Ubuntu pre-built configs outselling Windows

## Sustained Performance

HX 370 at ~33W sustained (from earlier Framework 13 testing). Runs hot (up to 100C) but maintains performance. Open-source EC firmware allows fan curve customization.

## Assessment

Best Linux laptop ecosystem. The redesigned chassis with 74 Wh battery is a significant upgrade. LPCAMM2 is a standout feature. AMD variant still uses Strix Point (not Gorgon Point).
